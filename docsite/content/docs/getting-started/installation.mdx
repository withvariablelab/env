## Install the package

```bash title="terminal"
pnpm add @variablelab/env
```

## Pick a schema validator

`@variablelab/env` is **agnostic to the schema validator** — the core relies on [Standard Schema](https://github.com/standard-schema/standard-schema), so any Standard Schema–compatible validator works (Zod, Valibot, ArkType, …). Install the one you'll actually use; you don't need any of them if you're plugging in your own.

The docs and the opt-in primitives at `@variablelab/env/zod` are written against Zod, so it's the most common pick:

```bash title="terminal"
pnpm add zod
```

## Peer dependencies

Peers are **optional** — install only the ones whose entrypoints you import:

| If you import…           | Install                  |
| ------------------------ | ------------------------ |
| `@variablelab/env/zod`      | `zod@^4`                 |
| `@variablelab/env/vite`     | `vite@>=5`               |
| `@variablelab/env/react`    | `react@>=19`, `react-dom@>=19` |
| `@variablelab/env/fs`       | _(none — Node-compat built-ins)_ |
