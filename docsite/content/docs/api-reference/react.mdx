The `@variablelab/env/react` entrypoint is the React integration for server-rendered apps — SSR (request-time) or SSG (build-time). Render `<EnvScript runtimeEnv={…} />` in your document. It writes the object into a `<script id="env" type="application/json">` tag, and in the browser `readEnv()` (and so `defineEnv` without `runtimeEnv`) parses it and caches it at `window.__env`.

## Exports

| Export      | Kind       | Summary                                                                                |
| ----------- | ---------- | -------------------------------------------------------------------------------------- |
| `EnvScript` | Component  | Serializes the `runtimeEnv` object you pass it into a `<script id="env" type="application/json">` element. You pick the public values. |
