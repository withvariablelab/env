The `@variablelab/env/react` entrypoint is the React integration for server-rendered apps — SSR (request-time) or SSG (build-time). Render `<EnvScript />` in your document and the resolved env shows up at `window.__env` before client code runs.

## Exports

| Export      | Kind       | Summary                                                                                |
| ----------- | ---------- | -------------------------------------------------------------------------------------- |
| `EnvScript` | Component  | Serializes the public branch of your resolved env into a `<script id="env">` element.  |
